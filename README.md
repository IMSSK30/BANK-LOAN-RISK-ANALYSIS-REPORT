# Bank Loan Risk Analysis

- About This Project

I worked on this project to analyze bank loan data and identify the key factors that influence loan defaults.

The project analyzes **45,000 loan records** and follows a complete Data Analyst workflow:

SQL → Python → Power BI

The goal of this project was to understand customer risk, analyze loan portfolio performance, and provide business recommendations to reduce default risk.

--Tools Used

- SQL
- Python
- Power BI

-Project Steps
 1. SQL Analysis

I used SQL to perform:

- Data exploration
- Data quality checks
- Missing value analysis
- Duplicate checks
- Customer analysis
- Loan analysis
- Default analysis

I created around **35 SQL queries** to understand different patterns in the dataset.

 2. Python Analysis

I used Python for:

- Data loading
- Data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization
- Feature engineering

Created new features:

- Loan Burden Category
- Credit Score Category
- Income Category
- Age Category

The final cleaned dataset was exported and used for Power BI dashboard development.

3. Power BI Dashboard

I created an interactive dashboard with 4 pages:

Page 1: Executive Summary

- Overall loan portfolio overview
- Key business metrics
- Default analysis

Page 2: Customer Risk Analysis

- Customer risk segmentation
- Income-based risk analysis
- Credit score analysis
- Loan burden analysis

Page 3: Loan Portfolio Analysis

- Loan purpose analysis
- Portfolio exposure
- Default risk analysis
- Interest rate analysis

Page 4: Business Insights & Recommendations

- Key findings
- Risk factors
- Recommendations for reducing loan defaults


Key Insights

- Customers with high loan burden showed the highest default risk.
- Low-income customers had higher default rates.
- Debt Consolidation loans showed higher default risk compared to other purposes.
- Higher interest rates were associated with increased default risk.

Business Recommendations

- Improve credit assessment for high-risk customers.
- Closely monitor customers with high loan burden.
- Review lending strategies for high-risk loan categories.
- Use data-driven decisions for better risk management.
